# Historical notebook archive

These notebooks record early experiments, baselines, migration work, and
benchmark development. They are preserved for provenance but are not maintained
as user documentation. Some contain superseded claims or APIs.

Users should return to the two maintained notebooks in the parent directory:
`Quickstart.ipynb` and `Prion_Case_Study.ipynb`.

Peer reviewers should use the revision-pinned material under `scripts/` and
`results/` for the released benchmark rather than treating these prototypes as
the experimental record.
