# Tutorials

Start with one of the two maintained notebooks:

1. [`Quickstart.ipynb`](Quickstart.ipynb) introduces the public loader API with
   a local, credential-free example and a disabled remote-source template.
2. [`Prion_Case_Study.ipynb`](Prion_Case_Study.ipynb) demonstrates the complete
   shard-to-training path using the bundled 1QLX structure. Its coordinate
   perturbations and toy denoiser are explicitly educational, not molecular
   dynamics or a validated force field.

The [`archive/`](archive/) directory preserves historical prototypes for
project provenance. They are not maintained tutorials and can be ignored by
users.
